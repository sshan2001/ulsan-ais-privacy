# ulsan-ais-privacy# 울산항 알리미 개인정보처리방침

최종 업데이트: 2026-06-11

울산항 알리미는 사용자 개인정보를 중요하게 생각합니다.

## 수집 정보

앱은 다음 정보를 처리할 수 있습니다.

* Firebase Cloud Messaging(FCM) 토큰
* 알림 설정 정보
* 서비스 오류 분석용 기술 정보

## 이용 목적

* 선박 감시 알림 제공
* 푸시 알림 발송
* 서비스 품질 개선

## 제3자 제공

앱은 개인정보를 판매하거나 제3자에게 제공하지 않습니다.

다만 서비스 운영을 위해 다음 서비스가 사용될 수 있습니다.

* Google Firebase
* Google Play Services
